- SHRINK is the dominant depth mover: removing it lifts parietal p50 4.58 -> 5.82

6. MUTUALLY-EXCLUSIVE GATES (the headline finding)
--------------------------------------------------
- Max parietal p50 the station can produce = 6.56 mm (alloff_i1: shrink DISABLED,
  interp-guides 1). Guide p50 = 8.085; +-20% band = [6.47, 9.70]. So the depth p50
  gate *can* pass — but ONLY with the shrinkwrap switched OFF, which is the opposite
  of this slice's brief, and that config has insideBody = 611651.
- Above Surface 0.5 is the ONLY setting that reaches insideBody = 0, and it sets
  every depth percentile to 0.00 mm.
=> {depth p50 in band} requires shrink OFF; {insideBody <= 500} requires Above
   Surface 0.5. No setting satisfies both. With the brief's Above Surface 0.0 the
   station gives depth p50 ~4.5 and insideBody ~72k-230k: neither gate passes.
- temple p90 <= 1.2x guide (10.84 mm) is reachable ONLY via distance-to-guides 0.01
  (7.95 mm) — which collapses the count to 51549 (count gate needs 250k-310k) and
  still leaves parietal/temple p50 low.
  Corroboration: tools/openclinxr/evidence/hair-lanes/lanes.py, the earlier station
  that uses Above Surface 0.0 as its "collision-only" setting, also only reduced
  inside-body 42% -> 22% — never to ~0. Same node behaviour, independent station.

10. SCOPE / NOT TESTED / REMAINING
----------------------------------
SCOPE: local Blender render lane only. No Quest/WebXR runtime, no on-headset evidence.
NOT TESTED: hair-groom15 has NOT been validated on a worn headset; no WebXR capture;
  no performance/frame-budget measurement; no downstream consumer (arena/iwsdk) load.
REMAINING (do NOT add offsets — report-only per brief):
  - The depth p50 gate and the insideBody<=500 gate are mutually exclusive with this
    station's node semantics (section 6). A fixed shrinkwrap cannot both preserve
    guide depth and eliminate penetration.
  - Root cause hypothesis to test next: the Shrinkwrap node collapses the whole shell
    toward the surface regardless of Above Surface; a proper "collision-only" pass
    needs per-point closest-surface projection with a keep-out shell, not a global
    shrink. The depth-class split is a real win (section 5) and should be kept.
  - frontMiss 23204 (<=15000) and backMiss 45497 (<=5000) are additionally out of
    reach from this station: groom8a itself already had frontMiss ~6k / backMiss
    ~30k, so those thresholds post-date the base station's capability.
  - pinna proximity (174409) needs an ear/tuck pass independent of shrinkwrap.
