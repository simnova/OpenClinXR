0b. STATION-CODE DEVIATION (one line, crash fix, algorithm unchanged)
------------------------------------------------------------------------
interp_children.py line 452 (inside `if args.region_weight:`):
  old: (w[_r][_keep[_r]].sum(axis=1) > 0).sum()
  new: ((w[_r] * _keep[_r]).sum(axis=1) > 0).sum()
The old expression boolean-masks a (k,4) array to 1-D, then .sum(axis=1)
raises AxisError: EVERY build with --region-weight and any cross-boundary
candidate crashed. groom21 never built children, so it never hit this.
The fix preserves the author's intent (per-row kept-weight sums) and is
unreachable with default flags. Proof the default path is untouched:
rebuilt groom19 with all-default flags to /tmp -> points+radii sha
c75e203fbc66a6551c02e4b408f061612407922591901ed4b198154c25be92ed,
identical to the value groom21 RESULT sect 6 recorded for the same
rebuild. (Groom19's own 41dcdd57... is the compressed-FILE sha, not the
array sha; same bytes either way.)
