## What was wrong

`GET /runtime/asset-bundles/:bundleId` called `createEdChestPainLocalLearnerRuntimeAssetBundle()`
with no arguments and served the ED bay for every id. The returned bundle's `scenarioId` field was
set to the requested id, and that field is the entire input to `describeRuntimeBundleScenarioMatch`,
so a ward case served an ED cast and the mismatch reported itself as a match.

## Three assertions that could not fail, and the repair

This card was **rejected once** before it was accepted. Every `doneWhen` command passed and three
assertions were vacuous. Found by an adversarial diff pass costing $0.002, then confirmed by reading
the code rather than accepted on the report.

1. Clause (8), the counterweight meant to prove the seam changed nothing for shipped cases, built its
   expectation as `resolveScenarioActorCast(id).map(actorId).filter(id => stagedActorIds(bundle).includes(id))`
   and then asserted the bundle contained that filtered list. A bundle that dropped three of four
   actors passed. It now compares the served no-selection bundle field-for-field against
   `createEdChestPainLocalLearnerRuntimeAssetBundle()`, which is exact and unfilterable.
2. Clause (3)'s cast half compared `resolveScenarioActorCast(doc.scenarioId, doc)` for a reordered
   document against the original. On unreverted code the injected document was ignored, so both sides
   returned the same value and the comparison was equal either way.
3. Four clauses tested `bindInitialSceneContents` and `refuseIfCastDriftsFromSelection` directly. Those
   are planners with no production caller, so a refusal that exists only there is the correct-and-inert
   class this package exists to stop. They now read the served bundle's `equipment`,
   `equipmentPlacements` and staged actors.

**A regression the tautological counterweight could not see.** While repairing it, injecting a document
was measured to empty `equipment` and `equipmentPlacements` for `ward_delirium_med_rec_v1` and
`clinic_knee_pain_return_to_play_v1` while leaving `ed_chest_pain` unaffected. The cause was reading
silence as refusal; the rule was inverted so an authoring document that says nothing about equipment
no longer removes it. SC-01S re-measured this at the integrated head and both cases carry
`ecg_cart_equipment` and `iv_stand_equipment` with two `sceneManifest.equipmentPlacements`, deep-equal
to the uninjected default.
