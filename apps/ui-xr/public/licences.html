OpenClinXR is a web-based clinical-skills runtime. This page lists the third-party software and assets the learner-facing runtime is built from, together with their licences and any attribution those licences require.

The authoritative per-asset record lives in the project ledger: docs/openclinxr/third-party-asset-licence-ledger.md.
